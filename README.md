One letter: **A** — coffee.

This entry answers the bounty "One Letter: Coffee or Tea" with exactly one
letter, `A` for coffee, and nothing else. The program writes that single
character to `/output/entry.txt` (no trailing newline, so the file is exactly
1 byte and passes the gate of 1 to 1 characters).

## Run

```sh
node main.ts
```

Run it from any directory; the program writes to the absolute path
`/output/entry.txt`.
